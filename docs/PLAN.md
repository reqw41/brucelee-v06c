# План порта Bruce Lee (ZX) → Вектор-06Ц

Опора — решения двух удачных портов: **monty-v06c** (ванильный Вектор 64 КБ, образ .c00/.r0m с заставкой,
логика сверена шаг в шаг с оригиналом, звук ВИ53, README по шаблону) и **aticatac-v06c** (эталон на модели
оригинальной машины → JS-модель → i8080 со сверкой lock80; вывод по лучу с замещением на месте; часы ВИ53;
сверка боевого образа shipcheck; AY, если есть, иначе ВИ53; Турбо+). Сводка граблей — aticatac `docs/LESSONS.md`.

## Что такое ZX-версия (по skool, 04.11)
- Код 7,3 КБ (≈3700 команд Z80, 134 подпрограммы), IX/IY в 433 местах, 405 JR, 36 DJNZ, 13 LDIR.
- Данные: комнаты 6429–9338 (20 комнат, RLE, 12 КБ), тайлы фона 9800 (2 КБ) + цвета 6300, спрайты персонажей
  A000–BFFF (8 КБ: точки и маски, обе стороны), состояния/кадры Брюса, Ниндзя, Зелёного Ямо — CB32–CD9A.
- Вывод: вся сцена рисуется в теневой экран E000–FAFF (раскладка ZX, 6912 Б), затем `C29C` копирует его
  LDIR в 4000 (≈145 тыс. тактов) — на Векторе этого не будет: рисуем сразу в плоскости.
- Шрифт — ПЗУ ZX (3C00). Звук — бипер (9300 мелодии, 95E2 эффекты, под DI). Прерывание C003 (IM 2): ввод,
  флаг кадра FE02, счётчики. Переменные FE00–FEFF. Два игрока (Брюс по очереди), клавиатура/джойстик.
- В skool нет FB00–FDFF (тексты, таблица IM 2). Эталон — образ с ленты BUGFIX: `node stand/tapeload.js` → `build/zx_tap.bin`.

## Этапы (как в aticatac)
0. **Эталон ZX.** Сделано: образ с ленты, прогон `stand/zxrun.js`, темп `stand/zxtempo.js` (50 шагов/с).
   Дальше: сценарии ввода → эталонные прогоны по шагам (`play_loop` C7A4), запись в build/golden.
1. **JS-модель логики** (src/model): ход персонажей, ИИ Ниндзя и Ямо, лампы, ключи, падения, смена комнат,
   счёт, жизни, два игрока. Сверка по подпрограммам с Z80 (shadow) и по шагам (model_run).
2. **i8080** (src/i8080) против JS-модели (lock80). Механический перевод `z2i` из monty — как оракул и запас
   для меню/титула; горячие места — руками.
3. **Игра на Векторе** (src/vec): комната из тайлов в плоскости, спрайты по лучу с замещением на месте,
   ISR + часы ВИ53, клавиатура/джойстик «П», звук, заставка, сверка боевого образа (shipcheck), образ
   .c00/.r0m (64 КБ) и проверка на MiSTer.

## Память (оценка)
Экран 3 плоскости (8 цветов) 24 КБ + данные ~23 КБ + код i8080 ~10 КБ + буферы ~3 КБ ≈ 60 КБ — ванильный
Вектор, квазидиск не нужен. Теневой экран ZX (7,5 КБ) не переносится.

## Решения владельца (04.11.2026)
- 8 цветов, 3 плоскости; цель **50 Гц** как ZX (вывод прямо в плоскости, замещение по лучу, догоняющий шаг).
- Звук — ВИ53 (мелодия титула и эффекты бипера переложить).
- Выпуск — ROM .c00/.r0m 64 КБ с заставкой, ванильный Вектор, как monty.
