# Раскладка памяти Вектора (ваниль 64 КБ, 8 цветов) — с 04.11.2026

| Адреса | Что |
|---|---|
| 0000–00FF | `DI / LD SP / JP boot`, прерывание RST 7 (0038 -> isr) |
| 0100–… | код: логика (src/i8080: pers, room, game) + платформа (src/vec: plat, render, title, sound), таблицы звука CPC (src/i8080/gen/sound.asm, звуки победы и гибели — в дырах 15 и 8) и операций вывода |
| … | острова данных ZX (C0E5 клавиши, очки C96B, персонажи и описатели CB1C–CD9A, …), переменные и тексты ZX FB00–FCFF, FE00–FEFF (страница FD — таблица IM 2 — не переносится), sprempty |
| … | Z_SPRC — блоки кадров (враги — байт точек на строку, Брюс — маска + 3 слоя цвета); часть блоков — в дырах комнат |
| …–5AFF | amap — атрибуты клеток (как F800 ZX), 768 байт; want/disp/pp/wr_rects |
| 5B00–5B1F | пустые тайлы (бит на тайл; у ZX здесь нули) |
| 5B20–9FFF | **данные ZX по своим адресам** (логотип 5B50, фон карты 5D00, карта 6000, цвета тайлов 6300, комнаты 6400–9338, тексты 92C0/92E0, тайлы 9800); указатели внутри не правятся |
| 5D00–5FFF | на титуле — CMAP, карта символов экрана титула (в игре — копия карты комнаты) |
| 9339 | не используется (у ZX — сдвиговый регистр шума удара; звук с 06.11 — CPC, src/vec/sound.asm) |
| 9340–963F | шрифт ZX (ПЗУ 3D00–3FFF) — на месте звуковых данных ZX, которые на Векторе не нужны |
| 9640–969F | звуки CPC (SND_HI, src/i8080/gen/soundhi.asm), nz_sel/nz_to (шум на счётчик голоса) |
| 96A0–96FF | стек (STACK = 9700, 96 байт; глубина до 60 байт по замеру 06.11) |
| 9700–97FF | игра: полоса столбца STRIP (64 строки по 4 байта; на время рисования комнаты — операции на тайл); титул: BLK_SRC |
| 8000–9FFF | это же — невидимая плоскость: палитра парами (номер i и i+8 одинаковы) |
| A000, C000, E000 | видимые плоскости: бит 2 (зелёный), 1 (красный), 0 (синий) цвета ZX; номер палитры = цвет ZX |

- Экран ZX 256×192 — строки 32..223 Вектора: строка ZX L в столбце c плоскости P — байт (P + c)·256 + 223 − L.
- Логика пишет адреса ZX через EQU zc_xxxx / zv_xxxx (`tools/mkvecdata.py` -> src/i8080/gen/, не в git).
- Сверка логики (`tools/run80.js`) ходит по этой раскладке: карта ZX -> Вектор из .sym (`--ship` — боевой образ).
- Образ ROM (`tools/mksplash.py`, `src/vec/splash.asm`): 0000 код заставки, 0100.. игра (0000–9FFF) в ZX0,
  8000–FFFF картинка в 4 плоскостях; после клавиши — распаковка в 0000 и запуск.
- Низ занят почти до 0x5B00. Потоки комнат в ZX0 освободили 20 дыр ROOMHOLE_n (6,1 КБ, src/i8080/gen/roomz.asm):
  в дырах 3, 4, 7, 9..14, 19 — код вывода (src/vec/render_q*.asm, render_pl_*.asm), в остальных — часть кадров
  спрайтов. Переменные — внизу (самоизменяемые переходы в коде дыр run80 --ship знает по меткам hcodeN).
