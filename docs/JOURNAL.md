## Цвет как в monty/pyjamarama: враги — одна плоскость, Брюс — три цвета (05.11)
Решения владельца: Ниндзя — синий (E000), Ямо — зелёный (A000), рисуются OR без маски, при стирании плоскость
берётся из тайла; Брюс — три цвета (кожа жёлтая, штаны белые, волосы и пояс красные) с маской ZX, поверх врагов,
дырки маски — бумага клетки. Раскраска — правило по частям кадра (tools/bruce_zones.py), лист для согласования —
`python3 -I tools/bruce_sheet.py` (build/bruce/colors.png).
- Кадры (tools/mkvecdata.py): у врагов строка — байт точек, у Брюса — четвёрка (маска, точки C000 = все, A000 =
  жёлтый|белый, E000 = белый). Блоки — внизу (Z_SPRC) и в дырах потоков комнат (gen/sprhole.asm); таблица spr_ptr
  (сторона 0/1), spr_k (вид). Логика: spr_block возвращает вид, pix_collide читает точки с шагом 1 или 4.
  run80 — карта байтов спрайтов ZX из build/sprmap.json.
- Вывод (src/vec/render_q*.asm, tools/mkplanes.py -> render_pl_*.asm, код в дырах 3, 4, 7, 9..14, 19): плоскость
  клетки = ((тайл | точки врагов плоскости) & маска Брюса) | точки Брюса | (бумага ? дырки : 0). Показ Ниндзя
  перерисовывает только E000, Ямо — только A000, Брюса — все три (rp_ps). Быстрые пути: одна плоскость (rp_one),
  три плоскости (rp_all: на чёрной бумаге варианты по чернилам pz_v / cfq_v); вспышка оружия — общий путь.
  Полоса столбца — вся страница 9700 (64 строки по 4 байта), want/disp/pp — внизу.
- Проверки: veccompose — новая модель (враги OR, Брюс по четвёрке); vecsoak CHECK=5 20 тыс. кадров — 0, NEG=1/2/3
